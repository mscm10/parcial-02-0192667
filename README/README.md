# Parcial 02 – Landing Page Jadoo (Travel Agency)

Réplica en **HTML y CSS** de una landing page de agencia de viajes, hecha a partir de un diseño de Figma.

## Diseño original

🔗 [Travel Agency Landing Page – Figma Community](https://www.figma.com/design/OLyuTTNBAPAixzA0WMqtf3/Travel-Agency-Landing-Page--Community-?node-id=0-1&p=f&t=veO7fisWoQh0dGKo-0)

## Secciones

1. Barra de navegación y Hero
2. We Offer Best Services
3. Top Destinations
4. Book Your Next Trip In 3 Easy Steps
5. Testimonials y logos de aerolíneas
6. Suscripción y Footer
